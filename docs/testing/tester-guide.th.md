# คู่มือผู้ทดสอบ Lomra

[English](tester-guide.md) · ใช้เวลาประมาณ 30 นาที ไม่รวมเวลาดาวน์โหลด

ขอบคุณที่มาลองใช้ Lomra แอปแคนวาสบนเดสก์ท็อปที่สร้างภาพและโมเดล 3 มิติบนเครื่องของคุณเอง
เราทดสอบแอป ไม่ได้ทดสอบคุณ หยุดเมื่อไรก็ได้
ข้อความในแอปเป็นภาษาอังกฤษ คู่มือนี้จึงใช้ชื่อปุ่มตามที่เห็นในแอป

## ก่อนเริ่ม

- Windows 10 หรือ 11 (64-bit) และพื้นที่ว่างประมาณ 30 GB แนะนำแรม 16 GB
  ส่วน 3 มิติต้องใช้การ์ดจอ NVIDIA ที่มีหน่วยความจำ 6 GB ขึ้นไป ส่วนอื่นไม่ต้องใช้การ์ดนี้
- ขนาดดาวน์โหลด: ตัวแอป 160 MB, Ollama กับโมเดลแชต (เฉพาะโมเดล 2–3 GB), โมเดลภาพ 5.2 GB
  และถ้าทดสอบ 3 มิติอีก 5.3 GB ควรเริ่มดาวน์โหลดไว้ก่อน
- ใช้เครื่องของคุณเองและภาพที่ยินดีให้คนอื่นเห็น อย่าใช้ไฟล์ส่วนตัว ไฟล์งาน หรือไฟล์ลูกค้า
  **ไม่ต้องใช้ API key หรือบัญชีเสียเงิน**
- โมเดลในเครื่องทำงานบนเครื่องของคุณ แต่ Lomra ยังต่ออินเทอร์เน็ตเพื่อตรวจอัปเดต ดึงรายชื่อโมเดล
  และดาวน์โหลดสิ่งที่คุณกดยอมรับ ([รายการทั้งหมด ภาษาอังกฤษ](README.md#what-leaves-the-computer))
- ถ้าโฟลเดอร์ `Documents` สำรองไปยัง OneDrive โฟลเดอร์ Lomra จะถูกอัปโหลดไปด้วย

จดเวลาที่เริ่มแต่ละส่วน และจดว่ามีคนช่วยหรือไม่

## 1. ติดตั้ง (5 นาที)

1. เปิด[รุ่นล่าสุด](https://github.com/Nxdus/lomra-app/releases/latest) แล้วดาวน์โหลด
   `Lomra-<version>-windows-x64.exe` ใช้หน้านี้เท่านั้น
2. ตรวจไฟล์: เปิด PowerShell ในโฟลเดอร์ที่ดาวน์โหลด แล้วรัน
   `Get-FileHash .\Lomra-<version>-windows-x64.exe`
   เทียบกับค่า `sha256` ข้างชื่อไฟล์ในหน้ารุ่น ตัวพิมพ์เล็กหรือใหญ่ไม่มีผล ถ้าค่าไม่ตรงให้หยุดและแจ้งเรา
3. เปิดไฟล์ Lomra ยังไม่ได้ลงลายเซ็นดิจิทัล Windows อาจแสดง **Windows protected your PC**
   ถ้าค่าแฮชตรงและคุณสบายใจ ให้กด **More info → Run anyway**
   ถ้าไม่สบายใจให้หยุดตรงนี้ ผลนี้ก็มีประโยชน์
4. ถ้า Windows บล็อกโดยไม่มีทางไปต่อ ให้หยุดและแจ้งเรา อย่าปิดระบบป้องกันใด ๆ ของ Windows
5. Lomra จะติดตั้งให้ผู้ใช้ปัจจุบันโดยไม่ถามอะไร แล้วเปิดขึ้นมา

## 2. เปิดครั้งแรกและดาวน์โหลด (5 นาที แล้วรอ)

1. ในหน้าต่าง **Welcome to Lomra** เลือก **Start with blank canvas**
2. กดปุ่มเมนูที่มุมซ้ายล่าง แล้วเลือก **Settings** → **Local models**
3. **Ollama**: กดไอคอนดาวน์โหลด แล้วกด **Install** Windows อาจขออนุญาต
   ถ้าเปิดเป็นหน้าเว็บแทน ให้ติดตั้งจากหน้านั้นแล้วกด **Check again**
   ถ้ามี Ollama อยู่แล้วและขึ้นว่า **Not running** ให้กดไอคอนเริ่ม
4. เมื่อ Ollama ขึ้นว่า **Running** ให้ดาวน์โหลด **Qwen 3 4B** (ประมาณ 2.5 GB)
   หรือ **Llama 3.2 3B** (ประมาณ 2 GB) ถ้าเครื่องมีแรม 8 GB
5. **Stable Diffusion**: ดาวน์โหลด **SD Turbo** แล้วกด **Download** ในหน้าต่างยืนยัน
6. **3D models**: ถ้าการ์ดจอใช้ได้ ให้ดาวน์โหลด **TripoSR** ถ้า Lomra บอกว่าต้องใช้การ์ด NVIDIA
   หรือหน่วยความจำไม่พอ ให้จดประโยคนั้นแล้วข้ามส่วนที่ 5 ถือเป็นผลที่คาดไว้
7. รอจน SD Turbo และ TripoSR ขึ้นว่า **Installed** และเห็นโมเดลแชตในรายการของ Ollama
   ระหว่างนี้ปิดหน้า Settings ได้ แต่อย่าปิด Lomra
   ในรุ่นหลัง 0.0.7 ถ้าการดาวน์โหลดโมเดลภาพหรือ 3 มิติหยุดกลางคันจะขึ้นว่า **Paused**
   ให้กดไอคอนเล่น (**Resume download**) เพื่อโหลดต่อ

## 3. แชตกับโมเดลในเครื่อง (5 นาที)

1. ที่แผงพิมพ์ข้อความ เปิดรายการโมเดลแล้วกด **+** ข้าง **LLM**
   ตั้ง **Provider** เป็น **Ollama** เลือกโมเดล แล้วกด **Add model**
2. เปิดรายการอีกครั้ง โมเดลในเครื่องควรถูกเลือกอยู่ใต้ **LLM** ชื่อที่มีมาตั้งแต่แรกเป็นโมเดลออนไลน์ที่เสียเงิน
3. พิมพ์ `Suggest three ideas for a poster about the sea.` แล้วกด Enter
4. ผ่านเมื่อได้คำตอบ จดจำนวนวินาที

Lomra ใช้โมเดลแชตนี้ตีความทุกคำสั่ง จึงต้องทำส่วนนี้ก่อนส่วนถัดไป
คู่มือใช้คำสั่งภาษาอังกฤษเพื่อให้เทียบผลกันได้ ถ้ามีเวลา ลองพิมพ์ภาษาไทยและบอกเราว่าเป็นอย่างไร

## 4. สร้างภาพบนเครื่อง (5 นาที)

1. รายการโมเดล → **+** ข้าง **Image** → **Provider: Stable Diffusion** → **SD Turbo** → **Add model**
2. พิมพ์ `Make a picture of a small red robot on a white background.` แล้วกด Enter
3. ผ่านเมื่อภาพขึ้นบนแคนวาส จดจำนวนวินาที ถ้าได้แต่ข้อความ ให้ลองอีกครั้งด้วย
   `Generate an image of a small red robot.` แล้วแจ้งเรา

## 5. สร้างโมเดล 3 มิติ (5 นาที เฉพาะ NVIDIA 6 GB ขึ้นไป)

1. รายการโมเดล → **+** ข้าง **Model 3D** → **Provider: 3D models** → **TripoSR** → **Add model**
2. เลือกภาพหุ่นยนต์บนแคนวาส
3. พิมพ์ `Turn the selected picture into a 3D model.` แล้วกด Enter
4. ผ่านเมื่อโมเดล 3 มิติขึ้นมา และลากในโมเดลเพื่อหมุนได้

ถ้าอยู่ใน EU สหราชอาณาจักร หรือเกาหลีใต้ อย่าใช้โมเดล Hunyuan3D เพราะสัญญาอนุญาตไม่ครอบคลุม

## 6. Storyboard (5 นาที)

1. คลิกพื้นที่ว่างบนแคนวาสเพื่อไม่ให้เลือกอะไรค้างไว้
2. พิมพ์ `/storyboard` แล้วกด Enter จากนั้นพิมพ์
   `A red robot finds a lost kitten in the rain. Three shots.` แล้วกด Enter
3. อ่านเรื่องในแผงแชต แล้วกด **Use this story** (ไอคอนสเลต)
4. ผ่านเมื่อช็อตขึ้นบนแคนวาส คลิกขวาที่ช็อตหนึ่งแล้วเลือก **Generate image**
5. **อย่า**กด **Make video** เพราะใช้โมเดลออนไลน์ที่เสียเงิน

## 7. ปิดท้าย (3 นาที)

1. ปิด Lomra แล้วเปิดใหม่ งานของคุณยังอยู่หรือไม่
2. บอกเราว่าช่วงไหนยากที่สุด คุณคาดว่าจะเป็นอย่างไร และอยากเปิดใช้อีกแค่ไหน 1 ถึง 5

## แจ้งผล

- [แบบฟอร์มแจ้งปัญหาหรือความเห็น](https://github.com/Nxdus/lomra-app/issues/new/choose)
  (เปิดเผยต่อสาธารณะ ต้องมีบัญชี GitHub เขียนภาษาไทยได้) หรือตอบกลับคนที่ชวนคุณ
- ใส่รุ่น Lomra (ท้ายหน้า Settings) รุ่น Windows การ์ดจอและหน่วยความจำของการ์ด และข้อความผิดพลาดตามที่เห็น
- **อย่าส่ง API key รหัสผ่าน ไฟล์ส่วนตัว หรือภาพหน้าจอ Settings → Agents เพราะอาจเห็นอีเมลของคุณ**
- ถ้าคิดว่าเป็นปัญหาความปลอดภัย ให้แจ้งแบบส่วนตัวที่
  [หน้าความปลอดภัย](https://github.com/Nxdus/lomra-app/security/advisories/new)

## ถอนการติดตั้ง

1. ถ้าต้องการคืนพื้นที่ก่อน: **Settings → Local models** แล้วลบโมเดลภาพและ 3 มิติ
   ปุ่ม **Uninstall Ollama** จะลบโมเดล Ollama *ทั้งหมด* ในเครื่อง ใช้เฉพาะเมื่อก่อนหน้านี้คุณไม่มี Ollama
2. Windows **Settings → Apps → Installed apps → Lomra → Uninstall**
3. รายการต่อไปนี้จะยังอยู่จนกว่าคุณจะลบเอง
   - `Documents\Lomra` – แคนวาส แชต และภาพ คัดลอกสิ่งที่อยากเก็บไว้ก่อน
   - `%APPDATA%\desktop` – โมเดล การตั้งค่า และการล็อกอินในเบราว์เซอร์ของแอป
     ลบเฉพาะเมื่อมีไฟล์ `storage-secret.bin` อยู่ข้างใน
   - `%LOCALAPPDATA%\desktop-updater` – สำเนาตัวติดตั้ง
   - `%TEMP%\lomra-update` และ `%TEMP%\lomra-mcp` ถ้ามี
   - `%USERPROFILE%\.ollama` – โมเดลแชต ถ้าคุณเก็บ Ollama ไว้
